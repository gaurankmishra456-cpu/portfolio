# Adding photographs through GitHub

1. Open the `photography` folder in your GitHub repository.
2. Upload your image files there (JPG, PNG, WebP, GIF, and AVIF work well).
3. Commit and publish. The gallery page automatically finds and displays every image in this folder—there is no code or list to update.

Keep image files around 2000px on their longest edge and below 1 MB where practical for a fast gallery.
